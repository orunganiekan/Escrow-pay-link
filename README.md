# Escrow-pay-link

Escrow-backed Naira payment links for social commerce, powered by Next.js, Neon Postgres, Neon Auth, Privy Stellar Server Wallets, Paystack, and Stellar Testnet Claimable Balances.

See [`plan.md`](./plan.md) and [`system-design.md`](./system-design.md) for the product plan and architecture.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
